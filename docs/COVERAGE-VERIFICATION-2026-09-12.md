## 补测与统计修正

- 新增重复身份各字段冲突、迁移只读预演、超过一页的盘点、照片期限回填、过期感谢不复活、删除申请状态竞态、历史申请去标识、数据库异常与不存在记录的区别等行为测试。
- Node `require()` 执行原始 CommonJS，而 Vitest 4.1.11 的默认 V8 源码回读会请求 Vite 转换后的代码。实测删除 handler 原文 33138 字符，转换后 33366 字符，插入分号导致字符偏移不一致；执行过的迁移分支仍被标记为未覆盖。
- `native-cloud-v8-coverage.mjs` 继续使用锁定版本的官方 V8 采集器与统计实现，仅为本项目 cloudfunctions 下的原生 JavaScript 回读实际执行的源码。客户端 TypeScript 保留默认源映射，node_modules 不受此适配影响。
- 适配器不修改命中次数、覆盖率阈值或排除项。3 个适配器测试检查原文回读、客户端映射保留及采集函数原样委托。升级 Vitest 时必须重新验证该适配器，不能只更新版本。
