本文件是根据当前代码整理的待核对内容，不代表微信后台已经保存或生效。2026-09-11 更新。不得填写“未处理任何用户信息”。

## 开发者处理的信息

| 后台信息类型                           | 实际用途与填写建议                                                                                         |
| -------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| 选中的照片或视频信息                   | 仅使用你主动选择或拍摄的照片，用于拾取信息文字识别、存放位置说明、取卡交接证明及转交说明；不处理视频。     |
| 发布内容                               | 用于失物信息登记、查询匹配、交接、感谢反馈及举报投诉处理。感谢默认只发给拾卡者，另行同意后才公开至感谢墙。 |
| 操作日志                               | 用于异常排查、安全审计、反滥用及处理争议；安全审计日志最多保存60天。                                       |
| 自定义：微信 OpenID                    | 用于账号识别、身份绑定关联、资源权限控制及站内消息投递。                                                   |
| 自定义：姓名、学号、身份类别、校区     | 用于失卡匹配与认领核验，展示采用脱敏摘要；不将匹配结果宣称为学校官方身份认证。                             |
| 自定义：用户填写的地点、时间与私密特征 | 用于失物匹配和交接说明；不是设备 GPS 定位。                                                                |
| 剪贴板（如后台提供此类目）             | 用户点击复制联系邮箱时，仅写入运营者邮箱，不读取剪贴板内容。                                               |

照片选择通过 `wx.chooseMedia` 的相机/相册来源。以后台该接口的实际映射提示核对摄像头及所选照片声明；不能凭空增加定位、相册写入、手机号码、微信头像昵称、身份证号等没有使用的能力。不要添加错误的 `requiredPrivateInfos: ["chooseMedia"]`。

## 第三方服务与 SDK

不沿用“第三方 SDK 一概不用填”的旧建议。当前实际包含：

- 微信小程序平台能力：登录上下文、选取照片、隐私授权、内容安全检查及用户主动订阅消息。
- 腾讯云 CloudBase：数据库、云函数、照片存储；服务端使用 `wx-server-sdk`。这不是用户额外安装的客户端 SDK，但仍须在委托处理说明中披露。
- 腾讯云 OCR：服务端把卡片图片的 Base64 数据提交到 `ocr.tencentcloudapi.com` 的 `GeneralAccurateOCR`，默认区域 `ap-guangzhou`，用于提取姓名、学号等卡面文字。

在后台可选项中准确选择对应提供者/服务；如果“SDK”栏目只接受客户端 SDK，勿虚构客户端集成，应在自定义项目或补充文档说明实际服务端委托处理。保存前逐字段核对平台提示；还需取得指引生效状态截图。
