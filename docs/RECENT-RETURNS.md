# 近期暖心归还：接入与验收

## 已批准的产品范围

首页使用说明下方、黄色品牌卡片上方显示最近交还动态，每条两行，徽章仅作装饰，不排名。只读取真实交还记录，不将上传照片、提出认领或单纯转交官方点写成已经交还失主。无数据时显示空状态，不使用用户提供的张、李、王、陈、刘同学示例填充线上内容。

## 授权规则

账号设置提供匿名、部分姓名与部分学号、全名与部分学号三种展示方式。默认匿名；公开方式须由拾卡者本人明确选择，不能根据失主的感谢公开开关推断拾卡者授权。全名另行确认，完整学号永不公开。

授权适用于授权后完成的归还，不把既有记录中的个人信息追溯公开。服务端每次读取当前授权；撤回后后续读取恢复匿名，客户端再次显示首页时重新读取。已被第三方截图的内容无法通过撤回收回，设置说明应明确这一点。

## 部署前检查

现有账号不存储可还原的完整姓名。选择全名展示时，需要本人重新输入与已绑定资料一致的姓名，服务端核对姓名摘要后才保存公开姓名；切换为匿名或部分姓名时删除它。绑定资料不是学校官方身份认证。

- 此功能是此前文字审核之后新增的可选公开用途。用户此前已确认完成的后台隐私配置继续保留，不能将该确认冒充为新功能公开用途已配置。
- 新版准备对外使用时，后台姓名/学号用途及补充说明应描述：“本人自愿选择后，在近期暖心归还动态中展示授权后完成的交还记录及其选择的姓名公开形式和部分学号；默认匿名，可在账号设置撤回；完整学号和失主身份不公开。”
- 如果数据库查询新增索引，仅把准确索引纳入部署清单，不通过控制台临时开放数据库权限。
- 旧后端不支持新动作时，动态显示暂不可用，首页其余功能仍可使用；不得将接口不支持误报为没有归还记录。
- 不开通收费图片审核，不新增图片公开入口，不改变 PRIVATE 云存储，不上传开发包或正式发布。
